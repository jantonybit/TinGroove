Página oficial de suporte e privacidade do **TinGroove**, sequenciador de bateria para Windows
publicado na Microsoft Store por Jantonybit.

- Política de privacidade (PT-BR): `privacy-policy.html`
- Privacy policy (EN): `privacy-policy.en.html`
- Índice do site (GitHub Pages): `index.html`
- Rascunhos do listing e das políticas em Markdown: `PRIVACY.md`, `PRIVACY.en.md`, `listing/`
